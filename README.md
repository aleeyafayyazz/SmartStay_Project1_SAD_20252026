# SmartStay_Project1_SAD_20252026
<h1 align="center">🏡 FlexRent Rental System</h1>

<p align="center">
  A web-based system developed for managing venue bookings with smart features such as
  <b>dynamic pricing</b>, <b>smart matchmaker</b>, and <b>time-slot booking with buffer system</b>.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
  The FlexRent Rental System is a web-based platform developed to simplify and improve the process of renting and 
  managing various types of spaces. The system is designed to support multiple categories of rentable spaces such 
  as wedding halls, event venues, meeting rooms, studios, sports facilities, homestays, shop lots, and other rental properties.
</p>

<h2>✨ Key Features</h2>
<ul>
  <li><b>Dynamic Pricing</b> – adjusts rental prices based on demand, holidays, and local events.</li>
  <li><b>Smart Matchmaker</b> – recommends homestays based on user preferences and booking history.</li>
  <li><b>Time-Slot Booking</b> – supports hourly, daily, and monthly rental management.</li>
  <li><b>Smart Availability & Buffer System</b> – prevents overlapping bookings.</li>
  <li><b>Role Management</b> – supports both Seekers and Providers.</li>
</ul>
